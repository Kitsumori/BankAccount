# Sistema bancario por consola


Requisitos mínimos para considerarlo completo:

- Crear una clase BankAccount.
- Permitir depósitos y extracciones.
- Validar que no se pueda retirar más dinero del disponible.
- Mostrar saldo actual.
- Gestionar múltiples cuentas mediante colecciones.
- Implementar manejo de excepciones para entradas inválidas.
- Utilizar encapsulación mediante propiedades y campos privados
